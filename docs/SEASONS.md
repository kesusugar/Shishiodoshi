# 四季版プラン（春・夏・秋・冬）

> **状態**: S0〜S4 の実装は済み（決定: 切り替えはボタン、自動巡回は最後、筒の雪は見た目だけ、作る順は秋→春→冬、時間帯は昼だけ→のちに夕・夜を追加: `seasons/time.ts`）。残りは ref4 との見比べでの微調整と、自動巡回。作りは `docs/HANDOFF.md` の「四季」を参照。

参考画像: [ref4（四季の並び）](reference/ref4-four-seasons.webp)。同じ構図（筧・竹筒・支柱・当たり石・手水鉢・石灯籠・立っている竹）で、季節だけが違う。今の夏は ref3 に寄せてあるので、**夏は基準、春・秋・冬を足す**。

## 0. 方針

- **シーンは1つ。季節は「値」と「いくつかの見た目の部品」で切り替える。**竹・石・鉢・水・音の物理と、水の描画は4季節で共通のまま使う（ししおどしの動きは季節で変わらない）
- 季節の値は `src/scene/seasons/`（今は `summer.ts` だけ）に足していく。夏の見た目は**変えない**（各段階で夏のスクリーンショットが前と同じことを確かめる）
- 季節ごとに変わるものは、ref4 を見比べて次の表にまとめた。この表が作る内容のすべて

## 2. 仕組み

### 2.1 季節の値を増やす（`seasons/types.ts`）
今の `Season` に次を足す。**季節を足すときは、このファイルに値を書くだけ**にするのが目標。

- 光: 太陽の色・高さ・向き・強さ（今のとおり）に加えて、**空の光の強さと色、曇りの度合い（影の柔らかさ）、霞の色と濃さ、露出**
- 背景の木（環境の球）: 葉の色・明るさ、**花の色と多さ、雪の量、幹の見え方、ボケの色**
- 頭上の葉（木漏れ日）: 葉の多さと形、**葉を通る光の色**（春は淡いピンク、秋は橙。これで光そのものが季節の色になる）
- 庭: 手前の枝の種類（カエデ／桜／裸の枝）、落ち葉・花びらの種類と数と色、シダの色、雪の量
- 空から降るもの: 種類（花びら／葉／雪）、数、落ちる速さ、揺れの強さ
- 苔・竹・石の色味、鉢の水の色
- 風の強さ、環境音（次項）

### 2.2 シェーダーの重ね掛けを整理する（最初にやる下準備）
今は石・鉢・地面などが `onBeforeCompile` を直接上書きしていて、**さらに「雪」を重ねられない**。1つの材質に複数の処理を順に足せる小さな道具（`chainCompile`）を作って、既存のコードをそれに載せ替える。夏の見た目が変わっていないことをスクリーンショットで確かめてから先に進む。

### 2.3 季節の切り替え
- 画面に季節ボタン（春 夏 秋 冬）を出し、`?season=spring|summer|autumn|winter` でも指定できる（撮影ツール用）。選んだ季節はブラウザに覚えさせる
- 切り替えは「暗転 → 入れ替え → 明るく戻る」の1〜2秒。背景の森の焼き直し（1回だけ）と庭の作り直しをこの間に行う（4季節分をあらかじめ持たず、使う季節だけをメモリに置く）
- 将来: 季節が自動でめぐる表示（1分ごとなど）を足せる作りにしておく

### 2.4 空から降るもの（新規 `render/falling.ts`）
- **奥や周りの大量の粒（雪・花びら・葉）**: 位置をシェーダーの中で時間から計算する。CPU はほぼ使わない。手前ほど大きく、被写界深度でボケる
- **鉢に落ちる粒**: 数十個だけ CPU で動かす（今のしぶき `Splash` と同じ作り）。鉢の水に着いたら小さな波紋を立て、花びらと葉は**そのまま水面に浮かぶ**（下の 2.5）。雪は水に着くと消え、ごく小さな波紋だけ立てる
- 数は画質の設定（`quality.ts`）で変える。スマホは PC の約 1/3

### 2.5 水面に浮かぶもの
今の `FloatingLeaves` は葉1枚ごとに1つのメッシュ。花びらが数十〜100 枚になるので、**1つのメッシュにまとめて（インスタンス化して）**、波に乗る動きはそのまま使う。種類（花びら／カエデ）・色・数は季節の値から決める。

### 2.6 雪（冬）
- **雪の材質**: 石・鉢・竹・木・灯籠・地面の材質に「上を向いた面に雪が積もる」処理を足す（今の苔と同じ考え方）。積もり方に凹凸と厚みのムラを付け、影の中は青みを帯びさせ、日が当たるところは細かくきらめかせる
- **雪の形**: 筒・筧・支柱の上には、実際に盛り上がった雪の形（少し大きい半円柱にこぶを付けたもの）を載せる。ref4 の筒の雪がこれ
- **筒の雪と物理**: 見た目だけにするか、重さとして物理に足すかは決めたい（下の「決めてほしいこと」）
- 地面: 砂利と苔の上に雪を薄く敷き、砂利の頭が少し出る。雪は光を柔らかく返すので、暗い影の中も真っ黒にしない

### 2.7 木漏れ日・光の色（`canopy.ts`, `env.ts`）
- 今の頭上の葉は「光を遮る影」だけを作っている。**葉を少し透ける光（色付き）を足す**。春は淡いピンク、秋は橙。ref4 の暖かさは主にこれで出る
- 冬は葉がほとんどないので、頭上には**細い枝の網目**を影として使う。太陽は弱めで、空全体の青白い光が主役（影が柔らかい）

### 2.8 音（季節ごとの空気）
すべて今までどおり合成する。**主役はコツンのまま**で、周りの音は小さく足す。

| | まわりの音 | 響き |
|---|---|---|
| 春 | 小鳥のさえずり（少し。周波数が上下する短い音の連なり）、そよ風 | 今のまま |
| 夏 | 今のとおり（葉ずれの風） | 今のまま |
| 秋 | 乾いた葉ずれ、虫の声（高い音を細かく揺らす） | 今のまま |
| 冬 | ほぼ無音に近い風。鳥や虫はなし | 雪が音を吸うので、反響を短く、高い音を控えめにする |

## 3. 進める順番と、各段階の確認

各段階の確認は、**4季節を同じカメラで撮って ref4 と並べる**（`tools/seasons-sheet.mjs` を作って、2×2 の比較画像を自動で出す）。カメラは ref4 の構図（少し高く、筒から鉢まで入る近さ）に合わせた `?view=seasons` を新しく作る。

| 段階 | 内容 | 確認 |
|---|---|---|
| **S0 下準備** | 季節の値を増やす（2.1）、シェーダーの重ね掛けの整理（2.2）、`?season=` と切り替えの操作（2.3）、比較画像のツールと `seasons` カメラ | 夏が前とまったく同じ。4季節を選べて、まだ夏の見た目のまま動く |
| **S1 秋** | 秋の値（光・背景・枝・シダ）、落ち葉の敷き詰め、鉢に浮かぶ葉、葉が降る（2.4）、葉を通る橙の光（2.7）、秋の音 | ref4 の秋と並べて、色と暖かさと落ち葉の量が近い |
| **S2 春** | 桜の枝と花房（手前と奥）、花びらの散る地面と水面、花びらが降る、淡いピンクの光と霞、春の音 | 春が ref4 に近い。花びらが水面で波に乗る |
| **S3 冬** | 雪の材質（2.6）、筒・筧・支柱・当たり石・鉢・灯籠の雪、雪の地面、裸の枝、雪が降る、曇りの光（2.7）、冬の音 | 冬が ref4 に近い。暗い部分が黒つぶれせず、雪がのっぺりしない |
| **S4 仕上げ** | 切り替えの滑らかさ、季節ごとの画質の調整（スマホの粒の数）、時間帯の微調整、ドキュメント | あなたの PC とスマホで見て、fps と見た目の感想をもらう |

夏から手を付けない理由: 今の夏はすでに ref3 に近く、そこを基準にして他の季節を作ったほうが比べやすい。冬（雪）が一番手間なので、仕組みが固まってから最後にやる。

## 4. リスクと対策

- **雪が「白い塊」に見える**: 積もる向き・厚み・ノイズ・影の青み・きらめきを重ねて作り、ref4 の冬と並べて確かめる
- **既存の材質を組み替えると夏が変わる**: S0 で夏のスクリーンショットを前後で比べる。変わったら進まない
- **花びら・雪・落ち葉で重くなる**: 奥の大量の粒は GPU だけで動かす。数は画質の設定で変える。あなたの PC と、スマホの実機でも fps を測ってもらう
- **雪の筒と物理の整合**: 決めてから作る（下）
- **鳥や虫の声が作り物っぽい**: ごく小さな音量で足し、聞いてもらって調整する。うるさければ切れるようにする

## 5. 決めてほしいこと（おすすめつき）

1. **切り替え方**: ボタンで選ぶ／自動でめぐる／両方 → **おすすめ: まずボタン。自動巡回は S4 で足す**
2. **筒の雪**: 見た目だけ／重さとして物理に足す（雪の重みで倒れるまでの時間が少し変わる。最初に倒れたとき雪が滑り落ちる演出も可能）→ **おすすめ: 最初は見た目だけ。あとで滑り落ちる演出を足すか決める**
3. **作る順**: 秋 → 春 → 冬 → **おすすめ（上の表のとおり）**
4. **時間帯**: ref4 はどの季節も昼の光。今は昼だけ → **おすすめ: 四季が終わってから、夕方・夜の追加を考える**
